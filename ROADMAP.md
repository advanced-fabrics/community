# Roadmap

## 1.0 release gates

- Stabilize `networking.advfab.org/v1`, Observation API v1, configuration v1 and provider protocol v1.
- Ship `afctl migrate` for the v0.26.2 API group transition without automatic destructive cleanup.
- Pass fresh-install, upgrade, provider-replacement and multi-cluster conformance suites.
- Publish threat model, security self-assessment, signed images and charts, provenance, SPDX and CycloneDX SBOMs.
- Demonstrate the reference runtime continuously for seven days before the final release vote.

## Post-1.0

- Add independent provider implementations and adopters.
- Form the Maintainer Council when governance thresholds are met.
- Pursue OpenSSF badges, CNCF Landscape inclusion and then CNCF Sandbox consideration based on real adoption evidence.
